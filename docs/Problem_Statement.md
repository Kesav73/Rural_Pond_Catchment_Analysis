We are developing an application for village management to plan the placement of ponds in their village. This involves analyzing contour maps, marking potential regions such as govt land for digging ponds, estimating the catchment area, querying rainfall data, estimating pond depth to catch heavy rainfall and presenting the results to the user.

Details:

The interface would be a UI with the option to select state and disctrit and then region
Once the region is selected and clicked enter, we need to fetch the map of that region, and the contour map too, and then we need to find out what regions are on the lower side and less height because thats where the water flows during rainfall, and then select a region in there that doesnnt have any houses and propose a pond there, and then give the dimensions of the pond by calculating the precipitation in that region using some api and then approximating the dimensions

All apis and services that are needed need to be searched and we need to make a complete system end to end
